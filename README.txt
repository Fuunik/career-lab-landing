# CAREER LAB — одностраничный сайт

Готовый адаптивный лендинг под Telegram-клуб «Поиск работы с ИИ».

## Перед публикацией
1. В `index.html` замените `PAYMENT_URL_HERE` на реальную ссылку оплаты.
2. В футере добавьте реальные ссылки на Политику конфиденциальности и Оферту.
3. При необходимости поменяйте цену `1 990 ₽`.
4. Если платёжная система после оплаты не умеет автоматически выдавать Telegram-доступ, используйте бота/платёжный сервис с автоматической выдачей инвайта.

## Структура
- index.html — страница
- styles.css — дизайн и мобильная адаптация

## Важно
Дизайн оригинальный, вдохновлённый современной Material/Android-эстетикой, но не использует официальный логотип Android и не выдаёт сайт за официальный ресурс Google/Android.

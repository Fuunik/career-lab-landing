# CAREER LAB — Landing Page

Адаптивный одностраничный лендинг для закрытого Telegram-клуба **CAREER LAB**, посвящённого поиску работы с использованием ИИ.

🔗 **Демо:** [fuunik.github.io/career-lab-landing](https://fuunik.github.io/career-lab-landing/)

## О проекте

CAREER LAB — лендинг, разработанный как посадочная страница для продажи платного доступа в закрытый Telegram-клуб. Страница построена по классической структуре продающего лендинга: оффер → боль аудитории → продукт → доказательства → тариф → FAQ → повторный призыв к действию.

Дизайн — оригинальный, вдохновлён современной Material/Android-эстетикой (тёмные панели, зелёный акцентный цвет, скруглённые карточки), без использования официальных логотипов и фирменного стиля Google/Android.

## Основные возможности страницы

- Сквозной сценарий продажи: от боли аудитории до оформления подписки;
- Блок с программой клуба (6 карточек с ключевыми темами);
- Пошаговый сценарий использования продукта;
- Блок с примерами материалов внутри клуба;
- Сегментация аудитории («для кого этот клуб»);
- Блок тарифа с ценой и кнопкой оплаты;
- Блок FAQ на базе `<details>/<summary>` без JavaScript;
- Полностью адаптивная вёрстка (десктоп / планшет / мобильный).

## Технологии

- HTML5
- CSS3 (Grid, Flexbox, `clamp()`, `min()`, медиа-запросы)
- Google Fonts (Roboto)
- Без сборщиков и фреймворков — чистый статический сайт

## Запуск проекта

Проект не требует сборки и зависимостей — это статические HTML/CSS-файлы.

**Локально:**
1. Скачать или клонировать репозиторий.
2. Открыть `index.html` в браузере.

**Через GitHub Pages:**
Сайт уже опубликован и доступен по ссылке в начале README.

## Перед запуском в продакшн

- [ ] Заменить `PAYMENT_URL_HERE` в `index.html` на реальную ссылку оплаты.
- [ ] Добавить в футере рабочие ссылки на Политику конфиденциальности и Оферту.
- [ ] Проверить актуальность цены (сейчас указано `1 990 ₽/мес`).
- [ ] Убедиться, что платёжный сервис умеет автоматически выдавать инвайт в Telegram после оплаты.
